## 使用方式

- 在 GitHub 上，点击上表中的「前往官网注册」即可访问对应入口。
- 下载任意 HTML 文件后，用浏览器打开即可自动跳转；页面同时提供手动跳转按钮。
- HTML 使用固定目标地址，通过 JavaScript 跳转，并提供 HTML 自动刷新后备机制。

GitHub 的文件预览页显示源码，不会执行 HTML 跳转。需要浏览器直接访问的短入口时，可在仓库的 **Settings → Pages** 中选择从 `main` 分支根目录发布，然后访问：

- `https://zunajumo06-cmd.github.io/chuixueyun_links/chuixueyun-1.html`
- `https://zunajumo06-cmd.github.io/chuixueyun_links/chuixueyun-2.html`

上述 Pages 地址仅在启用并完成部署后生效。
